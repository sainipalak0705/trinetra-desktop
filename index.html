Defense Layer

Meet the Six Agents

Each agent is a specialized subsystem with a distinct role. Together, they form an unbreakable defense chain.

AGENT 01

Gatekeeper

First line of defense. Monitors all process creation and file access attempts, blocking known malicious signatures before they can execute.

Process Monitor
AGENT 02

Watchdog

Behavioral anomaly detector. Tracks file modification velocity, entropy changes, and canary file triggers to identify ransomware activity in real time.

Behavioral Analysis
AGENT 03

Risk Analyzer

Continuous threat scoring engine. Combines signals from all agents to compute a real-time risk score and determine threat classification.

Threat Intelligence
AGENT 04

Policy Engine

Decision arbiter. Evaluates threat classifications against defined security policies and determines the appropriate automated response action.

Policy & Decision
AGENT 05

Enforcer

Rapid containment agent. Executes policy decisions by isolating processes, blocking network access, and preventing further file damage — in milliseconds.

Containment
AGENT 06

Vaultkeeper

Recovery orchestrator. Maintains cryptographically verified file snapshots and orchestrates restoration from trusted backup points — zero ransom, zero data loss.
